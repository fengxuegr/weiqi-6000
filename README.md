# 围棋级位测试 6000 题

一个离线可用的少儿围棋刷题页。6124 道级位题，分六档，每档十轮循环。

## 在 iPad / iPhone 上用

1. Safari 打开本页
2. 点底部「分享」→「添加到主屏幕」
3. 之后从桌面图标打开，全屏无地址栏，**断网也能做**

第一次打开会自动缓存全部内容（约 1.5 MB），之后不再需要网络。

## 在安卓上用

Chrome 打开 → 右上菜单 →「添加到主屏幕」。同样支持离线。

## 说明

- 进度存在浏览器本地，不上传任何服务器
- 换设备不互通；建议定期在首页「导出进度 JSON」备份
- 清除浏览器数据会丢失进度
