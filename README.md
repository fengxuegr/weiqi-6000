# 围棋级位测试 6000 题

一个离线可用的少儿围棋刷题页。6124 道级位题，分六档，每档十轮循环（前九轮每轮加 100 题，最后一轮做满整档）。

## 在 iPad / iPhone 上用

1. Safari 打开本页
2. 点底部「分享」→「添加到主屏幕」
3. 之后从桌面图标打开，全屏无地址栏，**断网也能做**

第一次打开会自动缓存全部内容（约 1.5 MB），之后不再需要网络。

## 在安卓上用

Chrome 打开 → 右上菜单 →「添加到主屏幕」。同样支持离线。

## 说明

- 进度存在浏览器本地，不上传任何服务器
- 换设备：在首页「备份 · 换设备」里点「显示本机进度二维码」，另一台设备打开本页后点「扫码导入」对准即可；也可以「从相册选二维码图片」，或勾选带上错题记录 / 活跃地图
- 单文件版（双击打开的 HTML）生成的二维码是进度码本身，用另一台设备的网页版扫码导入
- 清除浏览器数据会丢失进度，建议定期留一份二维码
